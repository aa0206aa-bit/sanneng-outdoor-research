# /review — 三能戶外報告品質審查

執行以下四個步驟，完成後輸出一份審查摘要，**不要自動修改任何檔案**。

## 步驟 1：自動驗證

執行 `python3 validate.py`，記錄輸出結果。

## 步驟 2：論述一致性檢查

閱讀報告，確認下列三組論述前後一致：

1. **定價定位**：CH4（商品角色架構）、CH6.4（定價策略）、CH10.4（電商通路）的定價建議是否互相呼應？
2. **目標客群**：CH5（消費者分析）與 CH10.2（目標客群建議）的族群描述是否一致？
3. **核心差異化**：CH1（執行摘要）與 CH10.1（核心定位建議）的品牌主張是否一致？

## 步驟 3：⚠️ 待驗證清單

列出報告中所有標記 ⚠️ 的數據，整理成表格：

| 行號 | 聲明內容 | 建議驗證方式 |

## 步驟 4：輸出審查摘要

格式如下：

```
## 報告審查結果 — YYYY-MM-DD

### 自動驗證
（貼上 validate.py 輸出）

### 論述一致性
- ✅ / ⚠️ 定價定位：（說明）
- ✅ / ⚠️ 目標客群：（說明）
- ✅ / ⚠️ 核心差異化：（說明）

### 待驗證數據（共 N 項）
（表格）

### 建議行動（優先序）
1. ...
2. ...
```
